1. INTRODUCTION                                       *gitcommitai-introduction*

gitcommitai.nvim is a Neovim plugin that uses AI to automatically generate
well-formatted Git commit messages following conventional commit standards.

Features:
  • AI-powered commit message generation via aichat
  • Conventional commit type selection
  • Automatic ticket extraction from branch names
  • Smart text wrapping and formatting
  • Configurable whitespace-only commit fallback
  • AI tool trailer management
  • Real-time subject line length indicator
  • Undo/redo support for message editing

================================================================================
2. REQUIREMENTS                                       *gitcommitai-requirements*

  • Neovim >= 0.9.0
  • aichat CLI tool (https://github.com/sigoden/aichat)
  • Git with interpret-trailers support
  • fmt command (for text wrapping)

3. INSTALLATION                                       *gitcommitai-installation*

Using lazy.nvim:
>lua
    {
      "yourusername/gitcommitai.nvim",
      ft = "gitcommit",
      opts = {
        model = "gemini:gemini-3.1-flash-lite-preview",
        role = "gitcommit",
      },
    }
<

Using packer.nvim:
>lua
    use {
      "yourusername/gitcommitai.nvim",
      ft = "gitcommit",
      config = function()
        require("gitcommitai").setup({
          model = "gemini:gemini-3.1-flash-lite-preview",
          role = "gitcommit",
        })
      end,
    }
<

4. CONFIGURATION                                     *gitcommitai-configuration*

Setup function:                                        *gitcommitai.setup()*

    require("gitcommitai").setup({opts})

    Configure the plugin. If no options are provided, defaults will be used.

    Parameters:~
        {opts} (table|nil) Configuration table with the following keys:

        • model (string): aichat model to use
          Default: "gemini:gemini-3.1-flash-lite-preview"

        • role (string): aichat role name
          Default: "gitcommit"

        • autocommit (boolean): Auto-generate commit message when opening
          COMMIT_EDITMSG
          Default: true

        • subject_warn_length (number): Subject line warning threshold
          Default: 50

        • subject_error_length (number): Subject line error threshold
          Default: 72

        • ticket_patterns (table): Patterns for extracting tickets from
          branch names
          Default: {
            "(%a+%-%d%d%d+)",  -- JIRA-123
            "(%a+_%d%d%d+)",   -- JIRA_123
            "#(%d+)",          -- #123
          }

        • jira_base_url (string): Base URL for Jira tickets
          Default: "https://issues.redhat.com/browse"

        • jira_uppercase (boolean): Convert ticket to uppercase
          Default: true

        • max_input_length (number): Max characters sent to aichat
          Default: 64000

        • whitespace_only_commit_message (table|function): Message used when
          staged changes only affect whitespace after ignoring spaces.
          Table keys:
            - enabled (boolean): Set false to use the normal AI path
            - subject (string): Commit subject
            - body (table|string): Commit body lines
            - include_files (boolean): Include affected staged files
            - files_heading (string): Heading before the file list
            - max_files (number): Maximum listed files
          Function form receives { files = {...}, file_count = n } and returns
          either a string or a table of message lines.

        • trailers (table): AI tool trailers
          Default: {
            { name = "Claude", line = "Co-Authored-By: Claude ..." },
            { name = "GitHub Copilot", line = "AI-assisted-by: ..." },
            ...
          }

        • conventional_commits (table): Conventional commit types
          Default: {
            { type = "feat", desc = "A new feature" },
            { type = "fix", desc = "A bug fix" },
            ...
          }

Example configuration:
>lua
    require("gitcommitai").setup({
      model = "claude:claude-3-5-sonnet-20241022",
      role = "gitcommit",
      autocommit = false,
      subject_warn_length = 60,
      jira_base_url = "https://jira.mycompany.com/browse",
      ticket_patterns = {
        "(%a+%-%d+)",  -- Allow any number of digits
      },
    })
<

5. USAGE                                                     *gitcommitai-usage*

COMMAND AND ACTION MENU~
                                                            *gitcommitai-command*
                                                            *:Gitcommitai*

Every action is available through the buffer-local `:Gitcommitai` command:

  • `:Gitcommitai` with no argument opens an interactive action menu.
  • `:Gitcommitai {action}` runs an action directly, with <Tab> completion,
    e.g. `:Gitcommitai regenerate`, `:Gitcommitai hint`, `:Gitcommitai cancel`.

Press |<leader>agg| to open the same menu without typing the command.

While a generation runs, an animated spinner is shown on the subject line and
the success notification includes the model that produced the message, e.g.
"Commit message generated (codex-blah)". Press |<leader>agx| or run
`:Gitcommitai cancel` to abort an in-flight request.

If `aichat` is not in `PATH`, or exits with an error, the plugin reports the
actual failure (including the first line of stderr) instead of a generic
message.

AUTOMATIC GENERATION~

When you run `git commit`, the plugin automatically:
1. Detects if COMMIT_EDITMSG buffer is empty
2. Sends git diff and status to aichat
3. Generates a conventional commit message
4. Formats and wraps the message body

Set |gitcommitai.setup()| option `autocommit = false` to disable automatic
generation and use manual keymaps only. When the buffer already has a message
(and you are not amending), a one-time hint reminds you that |<leader>agr| or
|:Gitcommitai| can regenerate it.

MANUAL REGENERATION~

Press |<leader>agr| to regenerate the commit message while preserving trailers.

REGENERATE WITH ANOTHER MODEL~

Press |<leader>agm| to regenerate using a one-off model selection from
`aichat --list-models`. This does not change your configured default model.

INLINE VERBOSE DIFF~

Press |<leader>agv| to toggle an inline staged diff preview in the commit
buffer. The preview is byte-for-byte identical to `git commit -v`: a scissors
line (respecting `core.commentChar`) followed by the raw, uncommented diff.

    # ------------------------ >8 ------------------------
    # Do not modify or remove the line above.
    # Everything below it will be ignored.
    diff --git a/file b/file
    ...

The raw diff is automatically stripped from the scissors line down right before
the buffer is written, so it never becomes part of the commit message
regardless of git's configured cleanup mode. A scissors block that git itself
added via `git commit -v` is handled the same way.

STAGED DIFF IN DIFFVIEW~

Press |<leader>agD| to open the staged diff in diffview.nvim for a side-by-side
view of the changes being committed. Requires diffview.nvim to be installed.

CONVENTIONAL COMMITS~

Press |<leader>agp| to:
1. Select a commit type (feat, fix, docs, etc.)
2. Optionally enter a scope
3. Apply the prefix to the subject line

TICKET INTEGRATION~

Press |<leader>agt| to extract tickets from branch names:

Branch examples:
  • feature/JIRA-1234-description → Jira: https://...../JIRA-1234
  • fix/#123-bug-fix → Fixes: #123

AI TRAILERS~

Press |<leader>aga| to add AI assistance acknowledgment trailers.

SUBJECT LINE INDICATOR~

Real-time visual feedback on subject line length:
  • Gray (≤50 chars): Recommended length
  • Yellow (51-72 chars): Warning
  • Red (>72 chars): Too long

6. KEYMAPS                                                 *gitcommitai-keymaps*

The following keymaps are available in gitcommit buffers:

                                                            *gitcommitai-<leader>agg*
<leader>agg         Open the gitcommitai action menu

                                                            *gitcommitai-<leader>agr*
<leader>agr         Regenerate commit message with AI

                                                            *gitcommitai-<leader>agh*
<leader>agh         Generate commit with hint

                                                            *gitcommitai-<leader>agm*
<leader>agm         Regenerate with selected AI model

                                                            *gitcommitai-<leader>agx*
<leader>agx         Cancel a running commit message generation

                                                            *gitcommitai-<leader>agv*
<leader>agv         Toggle inline verbose diff

                                                            *gitcommitai-<leader>agD*
<leader>agD         Show staged diff in diffview.nvim
                    Opens the staged changes in diffview.nvim for a
                    side-by-side view. Requires diffview.nvim to be
                    installed; shows a warning if not available.

                                                            *gitcommitai-<leader>agu*
<leader>agu         Undo/restore previous message

                                                            *gitcommitai-<leader>agc*
<leader>agc         Clear entire buffer

                                                            *gitcommitai-<leader>agd*
<leader>agd         Delete commit message body (keep trailers)

                                                            *gitcommitai-<leader>agt*
<leader>agt         Add ticket reference from branch name

                                                            *gitcommitai-<leader>agp*
<leader>agp         Apply conventional commit type

                                                            *gitcommitai-<leader>aga*
<leader>aga         Add AI or co-author trailer
